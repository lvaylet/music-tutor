# Synthèse sonore guitare via Web Audio API

Pour garantir un retour sonore instantané sans latence perceptible sur appareil tactile et sans dépendance à des fichiers audio externes lourds à charger sur le réseau, les sons de cordes pincées sont générés directement via la Web Audio API (modélisation Karplus-Strong / synthèse physique d'ondes de guitare).
