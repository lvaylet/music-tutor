# Rendu vectoriel SVG sur-mesure pour la portée

Pour afficher la clé de Sol et les 7 notes cibles (Do4 à Si4) de manière épurée, responsive et adaptée aux enfants, l'application utilise un composant SVG sur-mesure plutôt qu'une bibliothèque tierce de notation musicale (telle que VexFlow). Ce choix élimine les dépendances volumineuses et permet un contrôle graphique direct (tailles, contrastes, couleurs).
